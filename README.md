# EDL - Engineering Design Laboratory

## プロジェクト概要

EDL（Engineering Design Laboratory）は、学校の授業「デザイン実験」において開発している、**周囲の環境の質を視覚的に把握するためのシステム**です。

本プロジェクトでは、「環境の質を可視化する魔法」をテーマに、温度・湿度・騒音・二酸化炭素濃度（CO₂）などの環境要素をセンサで測定し、生活環境の状態を直感的に確認できるシステムの実現を目指しています。

取得した測定値をArduinoで処理し、それぞれの環境要素を8段階で評価します。評価結果をLEDゲージの点灯数によって表現することで、数値を詳しく確認しなくても周囲の環境の状態を把握できるようにします。

## 開発の目的

温度・湿度・騒音・CO₂濃度などの環境要素は、日常生活の快適性に関係しています。

しかし、これらを単純な数値として表示するだけでは、現在の環境がどの程度快適なのかを直感的に判断することは容易ではありません。

そこで、本プロジェクトでは各環境要素を8段階で評価し、その結果をLEDゲージで可視化することで、環境の状態を分かりやすく伝えることを目的としています。

## システムの仕組み

本システムは、主に以下の処理によって構成されます。

### 1. 環境情報の取得

各種センサを使用して、以下の4つの環境要素を測定します。

- **温度**：周囲の気温
- **湿度**：空気中の相対湿度
- **騒音**：周囲の音の大きさ
- **CO₂濃度**：空気質に関する指標

### 2. 測定値の評価

取得した測定値をArduinoで処理し、それぞれの環境要素を1〜8の8段階で評価します。

評価結果は、3ビットの2進数（000〜111）に変換して出力します。

### 3. LEDによる可視化

Arduinoから出力された信号を論理回路で処理し、LEDゲージの点灯数を制御します。

評価値に応じて1〜8個のLEDを点灯させ、環境の状態を視覚的に表現します。

また、4つの環境要素を順番に表示するため、レジスタを用いて評価結果を保持する構成を検討しています。

### システム構成

```text
各種環境センサ
      │
      ▼
   Arduino
（測定・8段階評価）
      │
      ▼
  3ビット信号出力
      │
      ▼
    論理回路
      │
      ▼
    レジスタ
      │
      ▼
  LEDゲージ表示
```

## 使用技術・部品

### 開発環境

| 項目 | 使用技術 |
|---|---|
| マイコン | Arduino UNO R4 WiFi |
| プログラミング言語 | C++ |
| 開発環境 | Visual Studio Code |
| ビルド・開発管理 | PlatformIO |
| フレームワーク | Arduino Framework |
| バージョン管理 | Git / GitHub |

### 主な使用予定部品

| 部品 | 用途 |
|---|---|
| AHT20 | 温度・湿度の測定 |
| MAX4466 | 騒音に関する信号の取得 |
| ENS160 | 空気質の測定 |
| 74HC173 | データの保持 |
| 74HC08 | AND論理演算 |
| 74HC32 | OR論理演算 |
| LEDアレイ | 評価結果の可視化 |

※ ENS160で取得するeCO₂は推定値であり、CO₂濃度を直接測定するものではありません。
